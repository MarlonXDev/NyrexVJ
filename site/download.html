Download

The newest build is always the Nightly release. Tagged versions, when there are any, are listed on the Releases page.

Windows

NyrexVJ.exe, a single file, no installer

Download NyrexVJ.exe

Also as a zip with the changelogs and readmes: NyrexVJ-windows-x64.zip

Windows SmartScreen may warn because the program is not code-signed. Choose More info, then Run anyway.

Linux

NyrexVJ-linux-x64, a single file

Download NyrexVJ-linux-x64

Also as an archive with the licences, the changelogs and a list of the libraries it uses: NyrexVJ-linux-x64.tar.gz

Make it executable with chmod +x NyrexVJ-linux-x64.

Checksums

Every build has a list of SHA-256 sums, and the program checks them itself when it updates. SHA256SUMS.txt

Video playback

The FFmpeg libraries are not part of NyrexVJ. Without them images and generative clips work, but video clips do not. The docs explain where to get them. FFmpeg is not part of NyrexVJ
