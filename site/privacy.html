Privacy

This website

This website is a set of static pages. It uses no cookies, no tracking, no analytics, no contact form, no comments and no embedded content, and it loads no fonts, scripts or images from other servers.

Hosting

The pages are served by GitHub Pages (GitHub, Inc.). Like every web server, it receives your IP address and the technical details of your request when you open a page and may keep them in server logs. The author of this site does not collect or evaluate visitor data. GitHub explains what it does in its own privacy statement. GitHub General Privacy Statement

Links and downloads

Links to GitHub leave this website, and the download buttons point to files that are hosted on GitHub. From there GitHub's terms and privacy statement apply.
