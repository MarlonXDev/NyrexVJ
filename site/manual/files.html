Files and the data folder

Chapter 33 of 37 · 2 min read

On this pageWhere it isWhat is in itBacking up and moving

#Where it is

NyrexVJ stores everything in its data folder. On Windows that is %APPDATA%\NyrexVJ, on Linux ~/.config/NyrexVJ, or $XDG_CONFIG_HOME/NyrexVJ if that is set. Set the environment variable NYREXVJ_DATA_DIR to use another folder. File, Open data folder and Settings, About open it.

#What is in it

ItemWhat it holds
settings.jsonYour program settings, including outputs, stage and sync
controls.jsonMIDI mappings
cues.jsonThe cue list
netsync_keyThe key of the network sync (keep it private, it is not in any package)
timeline.jsonThe lanes of the show timeline
autosave.json and recoveryThe last session and a rotating set of autosaves
presetsYour own presets
showsThe place the export window suggests for show packages
show_backupsYour own files that a show package import replaced, one folder for each import
packagesOne record for each installed community package, and a copy of its licence text
package_backupsFiles that an update, a replace or a removal of a community package moved away, one folder each time
shadersYour own shader files
textsYour own text clips, see Text, particles and effect chains
particlesYour own particle clips
chainsYour own effect chains
fontsYour own fonts for text clips
modelsYour own 3D models
mediaImages and videos
clipsScenes saved with the Clip Creator
nodesNode effects
languagesYour own language files
pluginsPlugins
venuesVenue setups
masksPictures used as masks
RecordingsYour recordings
nyrexvj.logThe log, useful for bug reports

#Backing up and moving

Copy the data folder to a safe place to back up everything. To move to another computer copy it into the same place there. Presets and sessions remember clips by name, so keep the file names of your shaders, models and media when you move them. To move one show with everything it uses, a show package is easier than copying the folder, see Show packages.

The token of the web interface is kept in a separate file in the folder. Do not share it.
